# Agent Context

Purpose: small onboarding layer for agents.

Read order:
1. `HANDSHAKE.md`
2. `AGENT_RULES.md`
3. `CONTEXT.md`
4. `development_log.md` only if history is needed
5. `../agent_proposals/INDEX.md` only for roadmap or prior research

Files:
- `HANDSHAKE.md`: ultra-short current handoff.
- `AGENT_RULES.md`: behavior and safety rules.
- `CONTEXT.md`: current architecture, commands, API, gotchas.
- `GLOBAL_ROADMAP.md`: consolidated roadmap, bug/feature queue, token policy.
- `development_log.md`: durable change history.
- `implementation_plan.md`: current short plan.
- `decisions/`: accepted ADRs.

Do not expand this folder with verbose prose. Use concise English.
