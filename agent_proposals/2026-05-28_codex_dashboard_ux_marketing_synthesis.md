# Proposal: UX Marketing Synthesis

Date: 2026-05-28  
Status: archive summary

## Position
The dashboard should be sold as a newsroom operating surface.

## Differentiators
- YouTube-native news metrics.
- Editorial caveats.
- Copyable briefs.
- Channel comparison by publishing behavior and audience response.
- Local-first data ownership.

## Avoid
- Generic BI language.
- Decorative dashboards without decisions.
- Metrics without interpretation.

## Acceptance
- Release notes and UI copy explain decisions, not chart inventory.
