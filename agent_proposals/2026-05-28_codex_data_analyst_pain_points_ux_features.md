# Proposal: Analyst Pain Points

Date: 2026-05-28  
Status: archive summary

## Pain Points
- Manual evidence copying.
- Weak freshness signals.
- Hard comparison across channels.
- Metrics without caveats.
- Repeated filtering work.

## Proposal
- Add copyable evidence layers.
- Add freshness and sample-size warnings.
- Add saved filters/views later.
- Add metric dictionary with caveats.

## Acceptance
- Analyst can explain a chart in a report with one copy action.
- The UI flags stale or misleading comparisons.
