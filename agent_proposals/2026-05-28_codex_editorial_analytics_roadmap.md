# Proposal: Editorial Analytics Roadmap

Date: 2026-05-28  
Status: archive summary

## Metrics
- Momentum and velocity.
- Publishing cadence.
- Engagement per view.
- Topic/keyword lift.
- Freshness-adjusted comparisons.

## UX
- Explain metric caveats inline.
- Convert chart signals into brief-ready text.
- Prefer editorial questions over raw chart categories.

## Acceptance
- A user can answer: what topic is rising, which channel moved first, and what action follows.
