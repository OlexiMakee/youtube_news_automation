# Proposal: Multi-Agent Development

Date: 2026-05-28
Status: archive summary

## Options
A1. Single main dev agent with proposal inbox. Lowest conflict risk.
A2. Parallel specialist agents with strict file ownership. Faster, higher merge risk.
A3. Review-board workflow. Slower, useful for architecture.

## Recommendation
Use A1 by default. Use A2 only for isolated research or docs.

## Rules
- One implementation owner at a time.
- Proposals require user or main-agent approval.
- Keep handoff docs short.

## Acceptance
- No agent implements another agent's proposal blindly.
